# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this
repository. Do not open a public issue. Include what you found, how to reproduce it, and what an attacker
could do with it. You will get an answer within 7 days.

In scope: the hub's API and sign-in, the adapters (especially anything that could send a blocked
command), the web app, and the privacy tooling. The threat model is in
[docs/security.md](docs/security.md).
